## Mood Mate project

The separate Mood Mate computing project is in [`docs/`](docs/). It is a browser-local mood journal with optional suggestions. The GitHub Pages workflow serves that folder at [Victoria-ctrl-dot.github.io/Chatbot](https://Victoria-ctrl-dot.github.io/Chatbot/). Enable **Settings → Pages → Build and deployment → GitHub Actions** if the workflow reports that Pages is not enabled. Journal data stays in the visitor's browser and is not sent to this repository.
